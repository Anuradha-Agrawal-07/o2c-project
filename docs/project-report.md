# Order to Cash (O2C) Simulation Project

## Title
Order to Cash (O2C) End-to-End Simulation Using Flask and SQLite

## Problem Statement
Manual handling of the Order to Cash process can lead to delays, duplicate entries, poor tracking, and difficulty in monitoring business documents. There is a need for a simple digital simulation that demonstrates the complete O2C workflow from customer creation to payment receipt.

## Objective
The objective of this project is to build a working O2C simulation system that allows users to manage customer and product master data, create sales orders, approve credit, post delivery, generate invoices, and record payments through a single dashboard.

## Solution / Features
This project provides a browser-based dashboard connected to a Flask backend and SQLite database. It supports:
- Customer master creation
- Product master creation
- Sales order generation
- Credit approval
- Delivery posting
- Invoice creation
- Payment collection
- Dashboard statistics
- Master data tables
- Transaction tables
- Reset all data option

## Process Flow
The workflow followed in this project is:
1. Customer creation
2. Product creation
3. Sales order creation
4. Credit approval
5. Delivery posting
6. Invoice generation
7. Payment collection
